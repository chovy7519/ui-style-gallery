关键 CSS 手法

可直接拿走复用的四条规则

01

把结构线露出来

边框不是装饰，而是结构本身；越粗、越可见，越接近粗野主义。

.section {
  border: 3px solid #000;
  padding: 14px;
}
02

拒绝圆角和阴影

把界面从“产品感”拉回原始网页，所有块面保持硬边。

* {
  border-radius: 0;
  box-shadow: none;
}
03

保留系统控件感

输入框和按钮像刚从浏览器里拿出来，不隐藏它们的原生属性。

input, button {
  border: 3px solid #000;
  background: #eee;
  font-family: "Courier New", monospace;
}
04

一块高饱和色

用一整块未经调和的颜色制造冲突，而不是细腻的渐变。

.stamp {
  background: #FFE600;
  color: #000;
  padding: 6px 10px;
  transform: rotate(-2deg);
}
