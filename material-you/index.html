状态层 State layers

hover 8%
focus / press 12%
disabled 12% 填充

状态层是同一套主色的透明度叠加，所有组件共用，因此 hover 的「重量」在全站一致，不靠手调颜色。

可直接复用的 4 条规则

  1. 先定义角色，再写组件

    组件只引用 primary / surface / outline 等角色变量，换种子色时整页自动协调。

    --primary / --surface-1 / --on-surface-variant
  2. 用表面亮度表达层级

    层级越高，表面从 surface 过渡到 surface-1/2/3，阴影只作为辅助，不堆叠多种黑色。

    surface → surface-1 → surface-2
  3. 圆角有尺度而非随机

    4px 用于输入框，16px 用于卡片，28px 用于容器与按钮，形成可记忆的节奏。

    4 / 8 / 16 / 28 / full
  4. 状态层统一透明度

    hover 8%、focus 与 press 12%，禁用态 12% 填充 + 38% 文字，所有交互组件复用。

    rgba(29,27,32,.08) / .12
