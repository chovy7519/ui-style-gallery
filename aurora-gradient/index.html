极光渐变Aurora Gradient

它靠尺度成立：把 3–4 个高饱和色团放到画布之外，用 90px 以上的高斯模糊拉成缓慢流动的色带，再用接近纯黑的底和低透明度前景压住亮度。辨识度来自色带的走向与颜色顺序，而不是某一种颜色。

这个风格靠什么成立

色带要“大、糊、慢”，前景要“暗、薄、亮边”，四件事缺一不可。

01大尺度色带 = conic + 模糊

.ribbon{
  width:110vw; height:34vw;
  background:conic-gradient(from 120deg,
    #4ade80, #38bdf8 35%,
    #a78bfa 62%, #4ade80);
  filter:blur(90px);
  opacity:.55;
  border-radius:50%;
}

02深底压亮度，前景要低不透明

body{background:#05070f}
.panel{
  background:rgba(10,17,32,.58);
  border:1px solid rgba(148,180,255,.18);
  backdrop-filter:blur(22px) saturate(150%);
}

031px 三色渐变描边

.panel::before{
  content:""; position:absolute; inset:0;
  padding:1px; border-radius:inherit;
  background:linear-gradient(100deg,
    rgba(74,222,128,.9),
    rgba(56,189,248,.7) 45%,
    rgba(167,139,250,.85));
  mask-composite:exclude;
}

04光晕只给“最该被点”的元素

.btn-primary{
  background:linear-gradient(100deg,
    #4ade80, #38bdf8 48%, #a78bfa);
  color:#04121c;
  box-shadow:0 14px 34px -14px
    rgba(56,189,248,.85);
}
