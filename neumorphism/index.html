UI Style 06 / 22 · 材质光影

新拟物Neumorphism

控件与背景同色，层次全靠一对阴影：亮侧在左上、暗侧在右下，光源固定。按压时阴影翻转为 inset，元素从「凸起」变成「凹陷」——没有边框，也没有色块。

底色#E6E9EF
亮侧阴影#FFFFFF
暗侧阴影#B4BFD0
文字#333D51
圆角16px
Aa
字体系统栈 600 / 700

下面每个组件都标注了状态；按 Tab 可查看键盘焦点环——新拟物的阴影对比度天然偏低，焦点必须另给一圈高对比实线。

凸起按钮

默认凸起 / hover 阴影加深抬升 / 按下变 inset 凹陷

圆形图标按钮

凸起圆形，按下时缩放 0.94 并内凹

开关

关闭态 track 内凹、滑块凸起；开启态滑块右移

凹陷输入框 / 文本域

输入区域整体内凹，聚焦时外描高对比焦点环

滑块

轨道内凹、滑块凸起，拖动时滑块翻转为凹陷

62 / 100

分段控件

外层凹槽，选中项以凸起高亮（默认选中「周」）

凸起卡片

大圆角凸起容器，承载内容与次级按钮

今日专注

与背景同色的卡片，靠左上亮、右下暗的一对阴影产生厚度，不使用边框。

禁用态

去掉立体阴影、文字压暗，指针为 not-allowed，不可聚焦
