涨跌从不只靠颜色：同时给出箭头与正负号；数字统一 tabular-nums，保证多行指标纵向对齐。

可直接复用的 4 条规则

  1. 三层近黑表面，不用大阴影

    背景、卡片、抬升态各差一档亮度，加 1px 冷色边框就足够分层，避免暗色页面发灰。

    #0B1120 → #111A2C → #16213A
  2. 数字必须等宽对齐

    所有指标、表格值使用 tabular-nums；主数值 42px，单位 12px 并降低亮度，形成明确的主次。

    font-variant-numeric:tabular-nums
  3. 涨跌三重编码

    颜色（绿/红）+ 箭头（▲/▼）+ 正负号同时出现，色觉障碍用户也能正确读取方向。

    ▲ 8.2% / ▼ 3.1%
  4. 强调色只给一个

    青色承担主操作与选中态，紫色只做图表第二序列；warning / error 只出现在状态语义里。

    accent #38BDF8 · violet #A78BFA
