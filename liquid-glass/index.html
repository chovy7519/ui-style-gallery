液态玻璃Liquid Glass

它在玻璃拟态上再加两层：折射——多层亮边与内高光把边缘压成透镜；流动——背景色团缓慢移动，玻璃透出的颜色随之改变。它追求的不是“像玻璃”，而是“像一层有厚度的液体贴在内容上”。

这个风格靠什么成立

比玻璃拟态多的是“透镜边缘”和“会变色的背景”，这两点决定了它不是普通毛玻璃。

01折射边缘：conic 渐变 + mask

.panel::before{
  inset:0; padding:1.5px; border-radius:inherit;
  background:conic-gradient(from 200deg,
    #fff, rgba(255,255,255,.18) 22%,
    #fff 42%, rgba(190,220,250,.35) 62%,
    #fff 82%, rgba(255,255,255,.25));
  mask-composite:exclude;
}

02过饱和的背板

.panel{
  background:linear-gradient(150deg,
    rgba(255,255,255,.66),
    rgba(255,255,255,.36));
  backdrop-filter:
    blur(30px) saturate(185%) brightness(1.06);
}

03镜面扫光（只在 hover 走一次）

.btn::after{
  content:""; position:absolute; inset:0;
  background:linear-gradient(115deg,
    transparent 30%,
    rgba(255,255,255,.75) 46%,
    transparent 62%);
  transform:translateX(-130%);
  transition:transform .65s;
}
.btn:hover::after{transform:translateX(130%);}

04背景必须缓慢流动

.blob{
  border-radius:50%;
  filter:blur(70px);
  animation:drift 26s ease-in-out infinite alternate;
}
@keyframes drift{
  to{transform:translate3d(6vw,4vh,0) scale(1.12)}
}
