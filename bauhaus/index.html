关键 CSS 手法

可直接拿走复用的四条规则

01

三原色只做结构

红黄蓝各自承担一种功能，不引入第四种强调色。

:root {
  --red: #D7261E;
  --yellow: #F2C300;
  --blue: #1D4ED8;
}
02

几何形状用 clip-path

三角、圆、方块都可以是纯 CSS，不需要图形资源。

.triangle {
  clip-path: polygon(50% 0, 100% 100%, 0 100%);
  background: #1D4ED8;
}
.circle {
  border-radius: 50%;
  background: #F2C300;
}
03

粗水平线切分版面

用一条三色横线把版面切成明确的段落。

.rule {
  height: 4px;
  background: linear-gradient(
    90deg,
    #D7261E 0 33.33%,
    #F2C300 33.33% 66.66%,
    #1D4ED8 66.66%
  );
}
04

功能即装饰

控件边角的小几何标记不是贴图，而是由同一套 CSS 变量生成。

.mark::before {
  content: "";
  display: block;
  width: 14px;
  height: 14px;
  background: #F2C300;
}
