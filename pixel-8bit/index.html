关键 CSS 手法

  1. 阶梯阴影：box-shadow: 4px 4px 0 #000 不写模糊，配合 steps(1) 过渡，位移是"跳格"而不是滑动。
  2. 伪像素字体：ui-monospace / Courier 加 letter-spacing:.12em 与 text-transform:uppercase，再叠 3px 3px 0 #000 硬阴影，接近点阵字重。
  3. 抖动网点：repeating-conic-gradient(#ffec27 0 25%, #000 0 50%) 配 background-size:10px 10px，得到经典 2×2 棋盘。
  4. NES 边框：内层 inset 2px 2px 0 light + inset -2px -2px 0 dark，外层再补 0 0 0 3px 描边，三层就够立体。
