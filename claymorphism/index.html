黏土拟态Claymorphism

它靠“同一个元素上的两种光”成立：左上用白色内阴影当受光面，右下用暖灰内阴影当背光面，再补一层很散的外投影，元素就从平面里鼓起来。大圆角与低饱和粉彩只是让这份体积更像软陶。

这个风格靠什么成立

体积感全在 box-shadow 里：外阴影决定“离地多高”，内阴影决定“鼓起来多少”。

01四层阴影捏出体积

.clay{
  box-shadow:
    12px 12px 28px rgba(176,152,131,.45),
    -9px -9px 22px rgba(255,255,255,.92),
    inset -7px -7px 14px rgba(176,152,131,.20),
    inset 7px 7px 16px rgba(255,255,255,.95);
}

02按压 = 把外阴影翻成内阴影

.clay:active{
  box-shadow:
    inset 7px 7px 14px rgba(176,152,131,.45),
    inset -7px -7px 14px rgba(255,255,255,.95);
}

03凹槽只留 inset，不要外投影

input{
  background:#efe5d9;
  box-shadow:
    inset 7px 7px 14px rgba(176,152,131,.40),
    inset -7px -7px 14px rgba(255,255,255,.92);
}

04低饱和粉彩 + 超大圆角

.clay{
  border-radius:32px;
  background:#f8f2ea;
  color:#332a47;      /* 深紫灰代替纯黑 */
  border:none;        /* 体积靠阴影，不靠描边 */
}
