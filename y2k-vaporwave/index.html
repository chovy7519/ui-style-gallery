关键 CSS 手法

  1. 透视网格：repeating-linear-gradient 画出 72px 与 64px 双色网格，再套 transform: perspective(300px) rotateX(74deg)，用 mask-image 让远处淡出。
  2. 铬合金字：五段式 linear-gradient（白→浅蓝→紫→白→粉）+ background-clip:text，再用 drop-shadow 叠一层硬投影，而不是柔光。
  3. 1998 斜面：box-shadow 同时写 inset 1px 1px 0 #fff 与 inset -2px -2px 0 暗边，外加 0 4px 0 实色底边，不需要图片。
  4. CRT 质感：repeating-linear-gradient(0deg, … 0 1px, transparent 1px 3px) 铺满固定层，配合 radial-gradient 星点，透明度控制在 5% 左右以免伤可读性。
