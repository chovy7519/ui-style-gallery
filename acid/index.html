关键 CSS 手法

  1. 硬投影：box-shadow: 5px 5px 0 #0a0a0a 不带模糊半径，hover 时增加到 9px 并把元素位移 -2px，产生"贴纸被掀起"的错觉。
  2. 描边优先：所有容器统一 border: 3px solid，禁用态切成 dashed，无需额外颜色即可区分。
  3. 歪斜网格：面板用 transform: rotate(-.3deg) 与 .28deg 交替，制造手工贴版的错位感，幅度必须小于 1deg 才不伤阅读。
  4. 荧光底纹：repeating-linear-gradient 双向 32px 黑线（透明度 7%）叠在荧光色上，既是网格也是噪点。
