关键 CSS 手法

  1. 双层切角：外层 padding:1px 铺青色渐变，内外都套同一个 clip-path: polygon(...)，切角处自然留下 1px 描边。
  2. 角标括号：按钮 ::before / ::after 各画两条边（左上青、右下品红），8px 见方，比整圈边框更像仪表盘刻度。
  3. 可读发光：text-shadow: 2px 0 #ff2e6e, -2px 0 #22e6ff 只做 2px 色散，正文不使用大半径模糊，避免发光糊字。
  4. CRT 覆盖层：固定定位的 repeating-linear-gradient 扫描线 + radial-gradient 暗角，mix-blend-mode:multiply 统一压暗，不遮交互。
