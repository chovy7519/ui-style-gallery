玻璃拟态Glassmorphism

它靠“隔着一层看背景”成立：先铺高对比色团，再叠半透明面板，用 backdrop-filter: blur() 把背后的颜色压成柔光，最后用 1px 亮描边和内侧高光交代玻璃厚度。少了背景、模糊、亮边任意一层，玻璃感都会塌掉。

这个风格靠什么成立

四条可直接复用的 CSS，去掉任何一条都会明显“不像玻璃”。

01半透明填充 + 背板模糊

.panel{
  background: linear-gradient(135deg,
    rgba(255,255,255,.16),
    rgba(255,255,255,.05));
  backdrop-filter: blur(22px) saturate(160%);
}

021px 渐变亮边（mask 裁切）

.panel::before{
  content:""; position:absolute; inset:0;
  padding:1px; border-radius:inherit;
  background:linear-gradient(140deg,
    rgba(255,255,255,.75),
    transparent 55%,
    rgba(255,255,255,.28));
  -webkit-mask:linear-gradient(#000 0 0) content-box,
                linear-gradient(#000 0 0);
  mask-composite:exclude;
}

03内高光切出厚度

box-shadow:
  inset 0 1px 0 rgba(255,255,255,.45),
  inset 0 -1px 0 rgba(255,255,255,.07),
  0 24px 60px -22px rgba(2,6,23,.9);

04背景必须比玻璃更“花”

body{
  background:
    radial-gradient(46% 38% at 14% 12%,
      rgba(124,92,255,.85), transparent 65%),
    radial-gradient(40% 34% at 86% 6%,
      rgba(34,211,238,.62), transparent 66%),
    #080c18;
}
