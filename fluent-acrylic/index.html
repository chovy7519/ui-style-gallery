高光揭示 Reveal

移动指针查看高光 radial-gradient 跟随 --mx / --my

所有卡片、按钮、图标按钮共享同一揭示层；用 pointermove 写入两个 CSS 变量，关闭动画偏好时自动禁用。

可直接复用的 4 条规则

  1. 亚克力 = 模糊 + 饱和 + 噪点

    半透明白只解决透明度，加入低透明度噪点才有真实材质感；噪点用内联 SVG feTurbulence 生成。

    blur(30px) saturate(125%) + noise 5%
  2. 深度只用三级阴影

    layer-2 用于按钮，layer-4 用于卡片，layer-8 用于浮层；每级都叠加 1px 内高光而不是纯黑投影。

    0 2px 4px / 0 4px 10px / 0 10px 26px
  3. 高光跟随指针，不跟随组件

    在容器上监听 pointermove 写入 --mx/--my，所有 .reveal 子元素自动获得同一套物理高光。

    --mx: 42%; --my: 18%
  4. 4px 圆角 + 2px 底线

    控件保持小圆角与清晰边线，焦点用 2px accent 描边或 2px 下划线，避免大圆角削弱工具感。

    border-radius:4px; border-bottom:2px
