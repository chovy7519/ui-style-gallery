这个风格靠什么成立

拟物不是画质感，是复刻“光怎么落在这个材质上”。

01拉丝金属 = 细密重复渐变

background:
  repeating-linear-gradient(90deg,
    rgba(255,255,255,.18) 0 1px,
    transparent 1px 4px),
  linear-gradient(180deg,
    #f6f3eb, #ded9cc 55%, #c3bcac);

02凹槽：上深下亮的内阴影

input{
  box-shadow:
    inset 0 3px 6px rgba(0,0,0,.28),
    inset 0 -1px 0 rgba(255,255,255,.75);
}

03按键行程：硬投影 + 位移

.btn{
  box-shadow:0 3px 0 #a19a8a,
             0 9px 14px rgba(0,0,0,.35);
}
.btn:active{
  transform:translateY(3px);
  box-shadow:inset 0 3px 7px rgba(0,0,0,.38);
}

04制造痕迹：1px 双线 + 螺丝

border:1px solid #8e8779;
box-shadow:
  inset 0 1px 0 #fff,
  inset 0 -1px 0 rgba(0,0,0,.18);
/* 四角螺丝用 4 层 */
/* radial-gradient 定位 10px 圆点 */
