关键 CSS 手法

  1. 宣纸底纹：双向 repeating-linear-gradient 4–5px 细线（透明度 2%–3%）叠加 radial-gradient 暖色中心，再撒几颗 radial-gradient 墨点。
  2. 双线朱金框：box-shadow: inset 0 0 0 4px 纸色, inset 0 0 0 5px 金色，一条 1px 金线就能把"装裱"的层次做出来。
  3. 篆刻印章：朱红方块 + inset 双内框 + 两层 radial-gradient 白斑模拟斑驳，再 rotate(-6deg) 落在角落。
  4. 云纹与月洞门：radial-gradient(circle at 50% 100%, …) 以 26px 为周期横向重复得到水波纹；月洞门用 border-radius:50% 加多层椭圆 radial-gradient 叠出远山。
